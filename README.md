# Connectors

MCP-based connectors that let Claude and other agents drive desktop host applications directly — starting with Revit.

See [`CONVENTIONS.md`](./CONVENTIONS.md) for the naming and testing conventions every connector follows.

## Connectors

- [`revit/`](./revit/) — Revit connector (Revit MCP Bridge + Revit MCP Server). In design; see [`revit/docs/PRD.md`](./revit/docs/PRD.md).
